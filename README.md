# REEL – Fashion Runway Platform UI

A static front-end UI inspired by YouTube, dedicated to fashion week content including runway shows, street style, interviews, and behind-the-scenes moments.

> Pure HTML & CSS project – no JavaScript, no backend

---

## Live Demo

https://mariarostamii.github.io/REEL/

---

## Features

- Fixed header with logo, search bar, upload/subscribe buttons, and avatar
- Collapsible-style sidebar with navigation sections (Home, Explore, Collections, Cities)
- Filter chips for content categories (SS 2025, AW 2025, Couture, etc.)
- Responsive video grid layout
- Hover effects on cards, buttons, and sidebar items
- "LIVE" badge and video duration badges on thumbnails
